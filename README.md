# NEXUS Digital Ecom

Site institucional em React + Vite.

## Como executar

1. Extraia o ZIP.
2. Abra a pasta `nexus-digital` no VS Code.
3. Abra o terminal dentro dessa pasta.
4. Execute:

```bash
npm install
npm run dev
```

5. Abra o endereço local mostrado pelo Vite (normalmente http://localhost:5173).

## WhatsApp

O número de atendimento está configurado em `src/App.jsx` na constante `WHATSAPP`:
`5511988301555`

O formulário abre o WhatsApp com os dados preenchidos. O visitante ainda precisa confirmar o envio no próprio WhatsApp.


Logo oficial incluído em `public/images/nexus-logo-white.png`, preparado para o fundo azul escuro do site. As animações CSS foram reforçadas no banner, notebook, foguete, etiquetas flutuantes e cartões.


As animações são implementadas em CSS, sem dependência de Framer Motion, para reduzir possíveis falhas na inicialização do React.

Logo circular oficial em `public/images/nexus-emblem-neon.png`, usado no notebook e na seção Sobre. O foguete, as órbitas, o brilho, o notebook e os indicadores flutuantes possuem animações CSS contínuas mais perceptíveis.
